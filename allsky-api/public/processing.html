Camera · Pipeline
–
The camera writes one image after each processing step of the merged HDR image (images/pipeline_NNN.jpg, 25 % size) for a single capture after it gets the signal SIGUSR2:
service: sudo systemctl kill -s SIGUSR2 allsky360-camera · make camera-run: sudo pkill -USR2 -f bin/allsky360-camera
Steps that are switched off in config.ini keep the image of an earlier run; the time of each image is shown in its tooltip.
